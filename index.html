Claude RTL Viewer

כלי לוקאלי לצפייה בתמלילי שיחות של Claude Code (קבצי .jsonl), עם תמיכה ב-RTL ו-LTR מעורבים. בחר באיזה אופן הצופה ייגש לקבצים:

תיקייה ישירות בדפדפן

ללא שרת — הצופה ניגש לקבצים דרך File System Access API. עובד רק בדפדפנים מבוססי Chromium (Chrome / Edge), ויידרש לאשר גישה. בחר את התיקייה projects שבתוך ~/.claude (בדרך כלל C:\Users\<user>\.claude\projects ב-Windows או ~/.claude/projects ב-macOS/Linux).

שרת מקומי (SSE)

מצריך הפעלה של ה-Bun server בתיקיית הפרויקט באמצעות bun run start. השרת קורא את הקבצים מהנתיב המקודד ב-server.ts (קבוע PROJECTS_DIR — בדרך כלל ~/.claude/projects) ומשדר עדכונים חיים. הצופה עצמו יכול לרוץ מכל מקום — דומיין מרוחק או מקומי — ולהתחבר אליו.

הפרויקט סטטי, ופועל כולו בדפדפן או מול שרת לוקאלי שלך — שום מידע מהתמלילים לא נשלח לשרת חיצוני.
