Claude RTL Viewer

כלי לצפייה בתמלילי שיחות של Claude Code (קבצי .jsonl), עם תמיכה ב-RTL ו-LTR מעורבים. בחר איך לקרוא את התמלילים:

תיקייה ישירות בדפדפן

לחץ "בחר תיקייה", נווט אל .claude/projects בתיקיית הבית שלך, ואשר את הגישה. הכל קורה בדפדפן — שום קובץ לא נשלח החוצה. נדרש Chrome או Edge.

הנתיב הוא בדרך כלל C:\Users\<user>\.claude\projects ב-Windows, או ~/.claude/projects ב-macOS / Linux.

שרת מקומי (SSE)

הרץ bun run start בתיקיית הפרויקט במחשב שלך, ואז הזן כאן את כתובת השרת (ברירת מחדל http://localhost:5577). השרת קורא את ~/.claude/projects ומשדר עדכונים בזמן אמת. עובד בכל דפדפן.

הפרויקט סטטי, ופועל כולו בדפדפן או מול שרת לוקאלי שלך — שום מידע מהתמלילים לא נשלח לשרת חיצוני.
